# OnOffSonic - Zephyr RTOS Project

Distance measurement using HC-SR04 ultrasonic sensor with toggle switch control on NUCLEO-H563ZI.

## Hardware Setup
- **MCU:** STM32 NUCLEO-H563ZI
- **Sensor:** HC-SR04 (Trig: D3, Echo: D4 via 1k/2k resistor divider)
- **Switch:** 3-Pin SPDT (D2)
- **LEDs:** Onboard Green (PB0) & Red (PG4)
